# CNN for acc prediction

## Intro Notes

- cut points have limited accuracy
- other papers use unsupervised machine learning techniques and greatly increase accuracy (~80%) as compared to cutpoint methods
- variable success on small samples
- most require hand-designed feature extraction
- deep learning identifies latent representations automatically - no need for feature extraction

## Methods
- uses the open-access Capture-24 dataset
	- Axivity AX3 wrist worn 24hrs
	- wore a camera and kept records for accurate labels
	- set at 100Hz

#### Deep learning framework
- operates on 2D images rather than 1D acc data
	- transforms signal processing problem into machine vision problem
- Steps
	- data was segmented into 30s intervals
	- signal to image conversion
	- deep features extracted using transfer learning
	- feature images transformed into an uncorrelated lower dimensional feature space and then used as inputs for BiLSTM RNN to classify behavior

#### Image encoding
- Gramian Angular Field - represents the temporal correlations between each pair of values in the time series
- first maps to polar coordinates - where the acceleration value becomes an angle and the time index becomes the radius
- then GAF produced - where for each pair of time points in the window the trigonometric is applied
	- the pairwise computations the nfill a square matrix, where rows and columnn correspond the time indices and entries represent how the two time points' values (acceleration in polar coordinates) are correlated
	- This the nacputres patterns like repetition, symmetry, and oscillation

#### Transfer learning
- theory is that if a model is trained well to perform one type of classification (extract relevant features well), this knowledge can the be applied to another domain after fine-tuning the model, this avoids the need to traina model from scratch
- they finetuned the state of the art pretrained ResNet101 model on the ImageNet dataset and then changed the final fully connected layer to predict the behaviors. ResNet101 is a 101-layer-deep CNN-based arch known for its stability and performance

#### Lower dimensionsal feature space
- using the deep latent features from the trained resnet model they then constructed a new representation using RICA
- RICA is different because has a better ability to work with sparse data (e.g. MVPA is relatively sparse in someone's day compared to Sed or Sleep)

#### BiLSTM Classification
- RNNs use sequential information as a sort of *memory* which is essential for time series (or temporally dependent) data.
- BiLSTM is a specific class that addresses problems in the original RNN arch 
	- e.g. thhe vanishing gradient problem
- this arch increases the temporal knowledge by feeding input both forwads and backwards, this allows the temporal pattern of signals across images to be used.

### Conventional Methods
-  **RF, ANN, SVM, DT, Naive Bayes**
- used features from other studies in 30s windows

### Training Testing Validation
- Random split into 67% training, 16.5% testings, and 16.5% validation
- LOO procedure to provide a realistic understanding of the generalizability of the results
- After the predictions were done for each access - the final prediction was based on voting among the labels for the three images
- Direct comparison by using same participants in each dataset for all models

### Performance Analysis
- confusion matrices
- sensitivity analysis to make sure BiLSTM wasn't overfitting
