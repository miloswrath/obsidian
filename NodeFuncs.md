## What is a Node Func?
---
**Essentially the same as any other function**

### **Requirements**

1. Track `temperature` (number)
    
2. Initial temperature = **68°F**
    
3. Min temperature = **60°F**
    
4. Max temperature = **80°F**
    
5. Buttons:
    
    - `+` increases by 1
        
    - `−` decreases by 1
        
6. Disable buttons at limits
    
7. Display a status label:
    
    - `"Cold"` if `< 65`
        
    - `"Comfortable"` if `65–75`
        
    - `"Hot"` if `> 75`
