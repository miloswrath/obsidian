## Query 1
---
```SQL
SELECT year, title, info.actors, info.release_date
FROM "Movies"
WHERE year = 2012
ORDER BY title
```

## Query 3
---
```SQL
SELECT info.image_url, info.genres, info.rating
FROM "Movies"
WHERE info.rating IN (8.3, 8.4, 8.5)
  AND contains(info.genres, 'Drama')
```

## Query 4
---
```SQL
SELECT title, info.genres, info.rank, info.running_time_secs
FROM "Movies"
WHERE info.running_time_secs > 7200
  AND info.rank > 20
  AND contains(info.genres, 'Thriller')
```
