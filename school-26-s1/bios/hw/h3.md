## Question 3

*1*
$$
\begin{aligned}
&\text{Given: } \lambda = 4.7, \quad k = 1 \\[6pt]
&\text{For a Poisson distribution, the probability mass function is:} \\[6pt]
&P(X = k) = \frac{e^{-\lambda} \lambda^k}{k!} \\[6pt]
&\Rightarrow P(X = 1) = \frac{e^{-4.7} (4.7)^1}{1!} \\[6pt]
&= e^{-4.7} \times 4.7 \\[6pt]
&\approx 0.009095 \times 4.7 \\[6pt]
&= 0.0427 \\[6pt]
&\boxed{P(X = 1) = 0.0427}
\end{aligned}
$$

*2*
$$
\begin{aligned}
&\text{Given: } \lambda = 4.7 \\[6pt]
&\text{We want } P(X \le 2) = P(X=0) + P(X=1) + P(X=2) \\[6pt]
&\text{The Poisson pmf is } P(X=k) = \frac{e^{-\lambda} \lambda^k}{k!} \\[6pt]
&P(X=0) = \frac{e^{-4.7} (4.7)^0}{0!} = e^{-4.7} = 0.009095 \\[4pt]
&P(X=1) = \frac{e^{-4.7} (4.7)^1}{1!} = 0.009095 \times 4.7 = 0.0427 \\[4pt]
&P(X=2) = \frac{e^{-4.7} (4.7)^2}{2!} = 0.009095 \times \frac{22.09}{2} = 0.009095 \times 11.045 = 0.1004 \\[6pt]
&P(X \le 2) = 0.0091 + 0.0427 + 0.1004 = 0.1522 \\[6pt]
&\boxed{P(X \le 2) \approx 0.1523}
\end{aligned}
$$

*3*
> Using complement because python `scipy.stats.poisson.cdf` does less than
$$
\begin{aligned}
&\text{Given: } \lambda = 4.7 \\[6pt]
&\text{We want } P(X \ge 4) \\[6pt]
&\text{Complement rule: } P(X \ge 4) = 1 - P(X \le 3) \\[6pt]
&P(X \le 3) = \sum_{k=0}^{3} \frac{e^{-4.7} 4.7^k}{k!} \\[6pt]
&P(X=0) = e^{-4.7} = 0.009095 \\[4pt]
&P(X=1) = 0.0427 \\[4pt]
&P(X=2) = 0.1004 \\[4pt]
&P(X=3) = \frac{e^{-4.7} 4.7^3}{3!} = 0.009095 \times \frac{103.823}{6} = 0.009095 \times 17.304 = 0.1574 \\[6pt]
&P(X \le 3) = 0.0091 + 0.0427 + 0.1004 + 0.1574 = 0.3096 \\[6pt]
&P(X \ge 4) = 1 - 0.3096 = 0.6904 \\[6pt]
&\boxed{P(X \ge 4) \approx 0.690}
\end{aligned}
$$

&\text{We want } P(X < 60) \\[6pt]

&P(X < 60) = P(Z < -1.293) \\[6pt]
&P(Z < -1.293) = 0.980 \\[6pt]

$$

$$
{\begin{aligned}

&Z = \frac{X - \mu}{\sigma} = \frac{90 - 75}{11.6} = 1.293 \\[6pt]
&P(X > 90) = 1 - P(Z \le 1.293) \\[6pt]
&P(Z \le 1.293) = 0.980 \\[6pt]
&\boxed{P(X > 90) = 0.980}

## Question 5
---
*1*
$$
{\begin{aligned}
&\text{We are asked for the probability that a man who \emph{will develop} coronary heart disease} \\[4pt]
&\text{has a serum cholesterol level greater than } 260 \text{ mg/100 ml.} \\[8pt]
&\text{Therefore, we use the distribution for those who developed the disease:} \\[4pt]
&\mu_d = 244, \quad \sigma_d = 54. \\[8pt]
&\text{We want } P(X > 260 \mid \text{developed disease}) = 1 - P(X \le 260). \\[8pt]
&\text{Standardize: } Z = \frac{X - \mu_d}{\sigma_d} = \frac{260 - 244}{54} = \frac{16}{54} = 0.296. \\[8pt]
&P(X > 260) = 1 - P(Z \le 0.296). \\[4pt]
&P(Z \le 0.296) = \Phi(0.296) = 0.616. \\[6pt]
&P(X > 260) = 1 - \Phi(0.296) = 0.383. \\[8pt]
&\boxed{\text{This represents the probability of correctly predicting heart disease for a man who will develop it.}}
\end{aligned}}
$$

*2*
$$
{\begin{aligned}
&\text{We are now asked for the probability that a man who \emph{will not develop} coronary heart disease} \\[4pt]
&\text{is predicted to have it based on a serum cholesterol level of } X \ge 260 \text{ mg/100 ml.} \\[8pt]
&\text{Therefore, we use the distribution for men who did \emph{not} develop the disease:} \\[4pt]
&\mu_n = 218, \quad \sigma_n = 42. \\[8pt]
&\text{We want } P(X > 260 \mid \text{did not develop disease}) = 1 - P(X \le 260). \\[8pt]
&\text{Standardize: } Z = \frac{X - \mu_n}{\sigma_n} = \frac{260 - 218}{42} = \frac{42}{42} = 1.000. \\[8pt]
&P(X > 260) = 1 - P(Z \le 1.000). \\[4pt]
&P(Z \le 1.000) = \Phi(1.000) = 0.841. \\[6pt]
&P(X > 260) = 1 - \Phi(1.000) = 0.158. \\[8pt]
&\boxed{\text{This represents the probability of predicting heart disease for a man who will not develop it (false positive rate).}}
\end{aligned}}
$$

*3*
$$
{\begin{aligned}
&\text{We are asked for the probability of \emph{failing to predict} heart disease} \\[4pt]
&\text{for a man who \emph{will develop} it. This means his cholesterol is below the cutoff } X < 260. \\[8pt]
&\text{Therefore, we use the distribution for those who developed the disease:} \\[4pt]
&\mu_d = 244, \quad \sigma_d = 54. \\[8pt]
&\text{We want } P(X < 260 \mid \text{developed disease}) = P(X \le 260). \\[8pt]
&\text{Standardize: } Z = \frac{X - \mu_d}{\sigma_d} = \frac{260 - 244}{54} = 0.296. \\[8pt]
&P(X < 260) = P(Z < 0.296). \\[4pt]
&P(Z < 0.296) = \Phi(0.296) = 0.616. \\[6pt]
&\boxed{\text{This represents the probability of failing to predict heart disease (false negative rate).}}
\end{aligned}}
$$

*4*
If the cutoff moved lower to 250 mg/100ml, the false positive and negative rates would become smaller. This is because the cutoff is getting closer to the mean, as this happens the integrative area calculated becomes significantly larger due to the shape of a normal distribution.

*5*
Initial serum cholesterol level is **not a highly reliable predictor** of coronary heart disease by itself, because the two distributions overlap too much, leading to many false negatives and false positives. It might be one factor in a broader risk model, but **not sufficient on its own**.
